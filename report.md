# CrescendoShield Research Report

## Abstract

CrescendoShield is a reproducible AI safety prototype for detecting and mitigating simulated multi-turn Crescendo-style jailbreak attacks. The system combines user input normalization, pattern-based risk detection, escalation monitoring, memory sanitization, an LLM wrapper, and output verification. It is designed to run on CPU/free-tier hardware while preserving an optional path for Hugging Face Llama-3.2-3B-Instruct integration.

## Motivation

Single-turn safety filters can miss attacks that unfold gradually. A user may begin with a benign request, introduce roleplay or authority framing, then escalate into prompt injection, context poisoning, or unsafe bypass requests. CrescendoShield treats the conversation as a risk trajectory rather than an isolated message.

## Methodology

The pipeline is:

```text
user_input -> risk_detector -> escalation_analyzer -> memory_sanitizer -> llm_wrapper -> output_verifier
```

The risk detector identifies jailbreak phrases, prompt injection syntax, roleplay bypasses, authority manipulation, and harmful escalation. The escalation analyzer tracks cumulative risk and trend over recent turns. The memory sanitizer removes high-risk context before it reaches the model. The output verifier catches unsafe completions and replaces them with a safe refusal.

## Dataset

The benchmark contains 2,500 simulated records:

- 500 benign examples
- 500 jailbreak examples
- 500 prompt injection examples
- 500 escalation examples
- 500 context poisoning examples

All examples are text-only and avoid operational harmful instructions.

## Results

Current benchmark snapshot:

```text
Attack Success Rate: 6.3%
Defense Success Rate: 93.7%
False Positive Rate: 0.0%
F1 Score: 0.967
Accuracy: 94.96%
```

These metrics are generated by `evaluation/evaluate.py` from actual pipeline predictions and rendered for the dashboard by `evaluation/generate_metrics.py`.

## Limitations

The benchmark is simulated and pattern-centered, so it does not fully cover paraphrased multilingual attacks or adversarially optimized prompts. The default LLM wrapper uses a safe deterministic stub for reproducibility. Real Llama-3.2-3B-Instruct evaluation requires Hugging Face access and additional hardware.

## Future Work

Future extensions include larger human-reviewed datasets, semantic embedding detectors, open-source guard model comparison, multilingual attack coverage, and richer real-time visualization of risk trajectories.

## Conclusion

CrescendoShield demonstrates a complete research-grade safety prototype with reproducible datasets, metrics, dashboard, report, and deployment path. It is suitable as a summer internship submission because it combines AI safety relevance, runnable engineering, evaluation rigor, and a polished interface.
